# My APP

## AI-Bloom（自己理解・自己受容アプリ）🌻

<p align="center">
  <img src="https://raw.githubusercontent.com/Pe-chan8/Pe-chan8/main/assets/app_ai_bloom.png" width="80%" />
</p>

**使用技術：**  
Ruby / Rails / Hotwire / PostgreSQL / Render / Neon / OpenAI API

## サービス概要

AI-bloom は、日々の小さな頑張りを“やさしく抱きしめ”、<br> 
AIの問いかけで自己理解と自信形成を支える **セルフコンパッション × 自己分析ツール**です。

「今日起きられた」「話しかけてみた」「詰まったけど諦めなかった」<br>
―― そんな誰にも言わないけれど、たしかに乗り越えた一歩を短文で残すだけで、<br> 
AIが“いちばんの味方”になり会話をします。

MVPでは日々の日記に対する共感やチアアップ、
本リリースではAIとの会話を通じて考えや行動の深掘り、自己分析を行い、<br>
”より自分を好きに”、”自信を持って人と向き合える自分に”なることを目的としています。

## このアプリが提供する価値

 - 日々の小さな行動や努力を言語化し、**自分自身で肯定できる状態をつくる**
 - AIとの対話を通じて、**思考や感情を整理し、自己理解を深める**
 - 強みや経験を自然に蓄積し、**就活・転職・人間関係など「評価される場」での自信につなげる**
 - 他者評価に依存せず、**自分の内側に安心できる土台を持った状態で行動できるよう支援する**

## 開発背景
キャリアアドバイザーとして多くの求職者と関わる中で、<br>
「自分には強みがない」「頑張っている実感が持てない」という声を頻繁に聞いてきました。

評価される場に立つ前に、まずは自分自身を肯定できる土台が必要だと感じたことが、<br>
AI-Bloom 開発のきっかけです。

## 制作への想い
AI-Bloom は、成果を出すためのツールではなく、「自分のいちばんの味方になる」ためのアプリです。<br>
自己理解と自己肯定が、次の一歩を踏み出す力になることを目指しています。

**制作開始日：** 2025/11/07  

**MVPリリース日：** 2025/12/18
 - 日記投稿 × AIバディからのやさしい返信
 - ソーシャルタイプ診断による自己理解
 - 複数のAIバディから自身に合ったAIバディを選択

**本リリース日：** 2026/01/31 予定
 - 投稿内容の深掘り
 - 自己分析（過去の投稿から強み・苦手な環境などをAIが言語化）

**アプリURL：** https://ai-bloom.onrender.com 

**GitHub URL：** https://github.com/Pe-chan8/AI-Bloom
